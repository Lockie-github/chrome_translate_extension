# 划词大模型翻译

一个使用自定义大模型 API 的 Chrome MV3 翻译扩展。支持弹窗中英文互译、整页网页翻译、网页划词和 PDF 文本翻译。

扩展版本为 `0.4.0`。

## 功能

- 弹窗中英文互译：自动识别输入语言并翻译为另一种语言。
- 词典式单词结果：按名词、动词、形容词等词性展示多个常用释义。
- 句子翻译：按句对齐显示双语结果，英文在上、中文在下。
- 整页网页翻译：支持逐句双语对照、原位替换为译文和恢复原文。
- 网页划词翻译：选中文本后点击悬浮按钮即可翻译。
- PDF 文本翻译：通过内置 PDF.js 阅读器选择并翻译 PDF 文字。
- 自定义模型服务：支持 OpenAI Chat Completions 兼容接口及多种认证方式。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `llm-selection-translator` 项目目录。
5. 在扩展列表中固定“划词大模型翻译”，方便从状态栏打开。

## 配置

1. 点击扩展图标，再点击“设置”。
2. 填写兼容 OpenAI Chat Completions 的 API URL。
3. 选择认证方式并填写 API Key。
4. 填写模型名称，再点击“测试翻译”保存设置并验证接口。

API Key 保存在本机的 `chrome.storage.local` 中，只会发送到配置的 API URL。

“目标语言”用于整页、网页划词和 PDF 划词翻译。“系统提示词”用于网页和 PDF 划词翻译。弹窗输入会自动判断中文或英文，并固定翻译为另一种语言。

## 使用

### 弹窗输入翻译

点击浏览器状态栏中的扩展图标，在输入框中输入中文或英文：

- `Enter`：开始翻译。
- `Shift + Enter`：输入换行。

输入单词或简短词语时，结果会按词性列出多个常用释义。输入短语、问题、句子或多行内容时，结果会逐句匹配显示，英文在上、中文在下。弹窗不请求或展示发音和音标。

设置中的“翻译句子时显示原文”默认开启。关闭后，不再逐句拆分结果，只显示完整译文。

翻译结果右上角提供“复制译文”按钮，只复制目标语言内容。

### 网页划词翻译

在网页中选中文本，点击选区附近出现的翻译悬浮按钮。翻译结果会显示在当前页面中，并支持复制和关闭。

也可以右键选中文本，使用“翻译选中文本”菜单。

### 整页网页翻译

1. 打开要翻译的网页，在扩展弹窗中点击“翻译网页”。扩展会将主页面已加载的可见文字分批发送到配置的 API，包括首屏以下的正文。关闭弹窗后，翻译会继续。
2. 在弹窗或设置中切换“网页翻译时显示原文”。这个开关默认开启，与弹窗输入翻译的“翻译句子时显示原文”分别配置。
3. 重新打开弹窗可查看进度。部分内容失败时，点击“重试未完成内容”。点击“恢复原文”可退出当前页面的翻译。

- **开启原文显示**时，正文每句原文下方紧跟对应译文。侧栏、导航和横向排列的控件在各自的文字区域内显示译文，并按可用宽度换行。
- **关闭原文显示**时，译文直接替换原位置的文字，链接仍可点击。

切换显示方式会复用已取得的译文，无需再次请求 API。

### PDF 文本翻译

Chrome 内置 PDF 查看器不是普通网页 DOM，扩展无法直接向其中注入悬浮按钮，因此扩展提供了自己的 PDF 文本阅读器：

- 打开以 `.pdf` 结尾的 URL 时，默认自动跳转到扩展阅读器(可通过设置关闭自动跳转)。
- 也可以点击扩展图标，再点击“用 PDF 文本阅读器打开当前页”。
- 对常见 datasheet 入口页，阅读器会先扫描页面中的真实 `.pdf` 链接。
- 阅读器使用 PDF.js 渲染页面并叠加可选择文字层，选中文字后可正常翻译。

## API 兼容

扩展发送 OpenAI Chat Completions 兼容请求：

```json
{
  "model": "your-model",
  "temperature": 0.2,
  "messages": [
    { "role": "system", "content": "..." },
    { "role": "user", "content": "..." }
  ]
}
```

支持以下响应字段：

- `choices[0].message.content`
- `choices[0].text`
- `output_text`
- `output[].content[].text`

弹窗词典和整页翻译都要求模型返回结构化 JSON。整页翻译会按返回的 ID 匹配原文和译文。扩展兼容 Markdown 代码围栏、JSON 字符串中的未转义换行以及尾随逗号。

## 限制

- 整页翻译跳过隐藏文字、输入框、可编辑区域和代码块。滚动后加载的新内容可在恢复原文后重新发起翻译。
- 网页整页翻译的范围是主页面 HTML 文字。iframe、Shadow DOM、图片和 Canvas 内容暂不支持。
- 扫描版、加密或复杂字体编码的 PDF 可能没有可选择文字层。
- 本地 `file://` PDF 需要在扩展详情页开启“允许访问文件网址”。
- 扫描版 PDF 需要额外接入 OCR 服务，本扩展目前不包含 OCR。
- 翻译质量、词性和释义数量取决于所配置模型的能力。

## 更新扩展

拉取或替换新版本文件后，在 `chrome://extensions/` 中找到本扩展并点击“重新加载”。如果使用压缩包，请先解压，再通过“加载已解压的扩展程序”选择目录。
