# 划词大模型翻译

一个使用自定义大模型 API 的 Chrome MV3 翻译扩展。支持在扩展弹窗中进行中英文互译，也支持网页划词和 PDF 文本翻译。

当前版本：`0.3.0`

## 功能

- 弹窗中英文互译：自动识别输入语言并翻译为另一种语言。
- 词典式单词结果：按名词、动词、形容词等词性展示多个常用释义。
- 句子翻译：短语、问题、句子和多行文本显示完整句意。
- 网页划词翻译：选中文本后点击悬浮按钮即可翻译。
- PDF 文本翻译：通过内置 PDF.js 阅读器选择并翻译 PDF 文字。
- 自定义模型服务：支持 OpenAI Chat Completions 兼容接口及多种认证方式。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `llm-selection-translator` 项目目录。
5. 在扩展列表中固定“划词大模型翻译”，方便从状态栏打开。

## 配置

1. 点击扩展图标，再点击“设置”。
2. 填写兼容 OpenAI Chat Completions 的 API URL。
3. 选择认证方式并填写 API Key。
4. 填写模型名称，保存后点击“测试连接”。

API Key 保存在本机的 `chrome.storage.local` 中，只会发送到配置的 API URL。

“目标语言”和“系统提示词”用于网页及 PDF 划词翻译。弹窗输入会自动判断中文或英文，并固定翻译为另一种语言。

## 使用

### 弹窗输入翻译

点击浏览器状态栏中的扩展图标，在输入框中输入中文或英文：

- `Enter`：开始翻译。
- `Shift + Enter`：输入换行。

输入单词或简短词语时，结果会按词性列出多个常用释义。输入短语、问题、句子或多行内容时，结果会显示完整句意。弹窗不请求或展示发音和音标。

### 网页划词翻译

在网页中选中文本，点击选区附近出现的翻译悬浮按钮。翻译结果会显示在当前页面中，并支持复制和关闭。

也可以右键选中文本，使用“翻译选中文本”菜单。

### PDF 文本翻译

Chrome 内置 PDF 查看器不是普通网页 DOM，扩展无法直接向其中注入悬浮按钮，因此扩展提供了自己的 PDF 文本阅读器：

- 打开以 `.pdf` 结尾的 URL 时，默认自动跳转到扩展阅读器(可通过设置关闭自动跳转)。
- 也可以点击扩展图标，再点击“用 PDF 文本阅读器打开当前页”。
- 对常见 datasheet 入口页，阅读器会先扫描页面中的真实 `.pdf` 链接。
- 阅读器使用 PDF.js 渲染页面并叠加可选择文字层，选中文字后可正常翻译。

## API 兼容

扩展发送 OpenAI Chat Completions 兼容请求：

```json
{
  "model": "your-model",
  "temperature": 0.2,
  "messages": [
    { "role": "system", "content": "..." },
    { "role": "user", "content": "..." }
  ]
}
```

支持以下响应字段：

- `choices[0].message.content`
- `choices[0].text`
- `output_text`
- `output[].content[].text`

弹窗词典模式会要求模型返回结构化 JSON。扩展能够兼容 Markdown 代码围栏、JSON 字符串中的未转义换行以及尾随逗号，但模型仍需具备基本的指令遵循能力。

## 限制

- 扫描版、加密或复杂字体编码的 PDF 可能没有可选择文字层。
- 本地 `file://` PDF 需要在扩展详情页开启“允许访问文件网址”。
- 扫描版 PDF 需要额外接入 OCR 服务，本扩展目前不包含 OCR。
- 翻译质量、词性和释义数量取决于所配置模型的能力。

## 更新扩展

拉取或替换新版本文件后，在 `chrome://extensions/` 中找到本扩展并点击“重新加载”。如果使用压缩包，请先解压，再通过“加载已解压的扩展程序”选择目录。
